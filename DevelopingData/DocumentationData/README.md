# DocumentationData

## Purpose
- Store the official project documentation and log history.
- Keep the master documentation as the single source of truth.

## Allowed files
- `README.md`
- `SourceDocument/`
- `LogData/`

## Must not be placed here
- Engine source files
- Audio cache
- Saved transcript payloads
- Random notes outside the approved documentation tree

## Naming rules
- Use English only.
- Keep documentation file names explicit and consistent.
- Use `README.md` in every folder.

## Related documentation path
- `DevelopingData/DocumentationData/SourceDocument/MASTER_PROJECT_DOCUMENTATION.md`
