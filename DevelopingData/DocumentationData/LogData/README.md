# LogData

## Purpose
- Store the project development log, version history, and critical revision records.
- Keep important implementation history separate from the main source documentation.

## Allowed files
- `README.md`
- `DEVELOPMENT_LOG.md`
- `DEVELOPMENT_LOG.docx`
- `VERSION_HISTORY.md`
- `VERSION_HISTORY.docx`
- `CRITICAL_REVISION_LOG.md`
- `CRITICAL_REVISION_LOG.docx`

## Must not be placed here
- Engine source files
- User transcript history
- Cache content
- Feature drafts that belong in the source documents

## Naming rules
- Use English only.
- Keep entries dated and versioned.
- Use one document role per file.

## Related documentation path
- `../SourceDocument/MASTER_PROJECT_DOCUMENTATION.md`
