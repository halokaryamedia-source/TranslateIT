# LogData

## Purpose
- Store the consolidated project history, version history, critical revision records, and improvement notes.
- Keep important implementation history separate from the main source documentation.

## Allowed files
- `README.md`
- `PROJECT_HISTORY.md`

## Must not be placed here
- Engine source files
- User transcript history
- Cache content
- Feature drafts that belong in the source documents

## Naming rules
- Use English only.
- Keep entries dated and versioned.
- Use one consolidated history document instead of splitting closely related records into separate files.

## Related documentation path
- `../SourceDocument/MASTER_PROJECT_DOCUMENTATION.md`
