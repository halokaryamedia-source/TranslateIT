# FeatureSpecificationDocument

## Purpose
- Define the planned and current TranslateIT feature set, status, inputs, outputs, and related implementation notes.

## Allowed files
- `README.md`
- `FEATURE_SPECIFICATION.md`
- `FEATURE_SPECIFICATION.docx`

## Must not be placed here
- Engine code
- Cache files
- Saved user sessions
- Unapproved feature drafts outside the official specification

## Naming rules
- Use English only.
- Keep feature names readable and stable.
- Use the approved status vocabulary.

## Related documentation path
- `../MASTER_PROJECT_DOCUMENTATION.md`
