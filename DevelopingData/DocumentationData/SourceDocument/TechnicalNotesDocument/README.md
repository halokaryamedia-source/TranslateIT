# TechnicalNotesDocument

## Purpose
- Capture the technical rules, decisions, risks, and benchmark assumptions for TranslateIT.

## Allowed files
- `README.md`
- `TECHNICAL_NOTES.md`
- `TECHNICAL_NOTES.docx`

## Must not be placed here
- Engine source code
- Temporary benchmark outputs
- User data
- Random scratch notes

## Naming rules
- Use English only.
- Keep decision notes concise and traceable.
- Keep technical terms consistent across documents.

## Related documentation path
- `../MASTER_PROJECT_DOCUMENTATION.md`
