# ProjectContextDocument

## Purpose
- Record the product context, problem statement, and project boundaries for TranslateIT.

## Allowed files
- `README.md`
- `PROJECT_CONTEXT.md`
- `PROJECT_CONTEXT.docx`

## Must not be placed here
- Engine implementation files
- User data
- Logs
- Unrelated notes

## Naming rules
- Use English only.
- Keep the document title in upper snake case.
- Keep the content focused on context and project intent.

## Related documentation path
- `../MASTER_PROJECT_DOCUMENTATION.md`
