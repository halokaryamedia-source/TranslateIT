# CudaSetupGuideDocument

## Purpose
- Hold CUDA readiness and troubleshooting guidance for TranslateIT Core App runtime.

## Allowed files
- `README.md`
- CUDA setup guide documents

## Must not be placed here
- Runtime logs
- Engine source files
- User transcript data
- Model files

## Naming rules
- Use English only.
- Keep guidance tied to official NVIDIA and PyTorch references.
