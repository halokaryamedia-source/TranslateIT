# Source Documentation

## Purpose

This folder contains the current source-of-truth project documentation after consolidating old `DocumentationData` materials.

## Documents

- `ProjectDocumentation.md` - current project overview and architecture direction.
- `SystemArchitecture.md` - runtime architecture and module ownership.
- `ManualTestGuide.md` - manual validation checklist.
- `ProjectHistory.md` - condensed project history.

## Rules

- Keep current source documentation here.
- Do not restore `DevelopingData/DocumentationData`.
- Historical reports belong in `DevelopingData/Documentation/Reports` only when still useful.
