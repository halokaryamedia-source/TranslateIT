# TranslateIT Documentation

## Purpose

This is the single documentation hub for TranslateIT.

All developer documentation, research, guides, templates, reports, and source references should live under this folder. Documentation should not be scattered across separate root-level `DeveloperData`, `Docs`, `DocumentationData`, or `Reports` trees.

## Layout

```text
Documentation/
  README.md
  Guides/
    Repository/
  Orientation/
  Reports/
    Engineering/
  Research/
    VoiceLab/
  Source/
    README.md
    ProjectDocumentation.md
    SystemArchitecture.md
    ManualTestGuide.md
    ProjectHistory.md
  Templates/
    Repository/
```

## Rules

- Keep documentation here.
- Keep executable validation scripts in `DevelopingData/Tooling`.
- Keep runtime app code in `EngineData`.
- Keep user runtime output in `UserData`.
- Do not create new root-level documentation folders.
