# ToolKitData

## Purpose
- Store helper material, templates, and approved tooling references for the project.

## Allowed files
- `README.md`
- Curated helper references
- Approved toolkit notes
- Dependency manifests for the local prototype runtime
- Local virtual environment folders created for approved development runs
- Model download helper scripts and temporary download cache
- `Scripts/` for internal setup, validation, CUDA, launch, and diagnostic scripts called by `TranslateIT.bat`

## Must not be placed here
- Engine runtime code
- Runtime-critical model files required by a released app
- User data
- Source documentation drafts
- Unapproved utilities

## Naming rules
- Use English only.
- Keep helper names explicit.
- Keep toolkit content curated and minimal.
