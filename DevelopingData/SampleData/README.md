# SampleData

## Purpose
- Hold non-sensitive sample inputs, references, and test examples for development.

## Allowed files
- `README.md`
- Curated sample assets
- Sample text or audio examples approved for testing

## Must not be placed here
- Live user transcript history
- Permanent saved sessions
- Engine source code
- Documentation drafts

## Naming rules
- Use English only.
- Use clear sample labels.
- Mark sample files so they cannot be confused with real user data.

## Related documentation path
- `../DocumentationData/SourceDocument/MASTER_PROJECT_DOCUMENTATION.md`
