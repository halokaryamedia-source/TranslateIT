# SavedTranscript

## Purpose
- Reserve a place for saved transcript session bundles and exported transcript material.

## Allowed files
- `README.md`
- Future approved saved transcript bundles

## Must not be placed here
- Temporary cache material
- Engine source files
- Documentation files
- Random session notes

## Naming rules
- Use English only.
- Use stable session or export names.
- Keep this folder for saved transcript material only.
