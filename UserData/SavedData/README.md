# SavedData

## Purpose
- Hold user-approved saved transcript sessions and exported files.
- Keep permanent user data separate from temporary cache material.

## Allowed files
- `README.md`
- Saved transcript sessions
- Exported files
- Saved replay audio only when the user chooses to save the session
- Approved subfolders such as `CustomVoice/` and `SavedTranscript/`

## Must not be placed here
- Temporary cache files
- Developer documentation
- Engine source files
- Auto-generated scratch material

## Naming rules
- Use English only.
- Use stable session names and explicit export labels.
- Keep saved material clearly separated from cache material.
