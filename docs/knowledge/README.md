# TranslateIT Knowledge Map

This directory contains only current repository knowledge owners. Historical reports and superseded state belong in Git history, not a parallel live documentation tree.

```text
flow.md
→ how work moves through context / diagnosis / proof

next-action.md
→ resume-critical current state + exactly one next step

current-validation.md
→ what current evidence can and cannot prove

source-ownership.md
→ semantic responsibility → current source owner

decisions/
→ durable decisions and why

operations/
→ retained repeatable operator/developer runbooks

skills/
→ project-skill inventory and activation rules
```

Current product/system law lives in `../foundation/`. Stable orientation lives in root `CONTEXT.md`. GitHub execution policy lives in root `GITHUB_RULES.md`.

Do not create duplicate roadmap/status/review/plan/session-memory hierarchies here.
