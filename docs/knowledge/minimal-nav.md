# Minimal Navigation

Use this file only as a routing index. It is not another policy owner.

## Resume

```text
AGENTS.md
-> CONTEXT.md
-> docs/knowledge/next-action.md
```

Then open only what the current task requires:

```text
Product/system policy
-> docs/foundation/

Source ownership
-> docs/knowledge/source-ownership.md

Skill selection
-> docs/knowledge/skills/activation-matrix.md

Durable decision reasoning
-> docs/knowledge/decision-log.md

Implementation
-> relevant current source + direct caller/contract only
```

## Historical Evidence

`DevelopingData`, `V1-Advance`, older branches, old reports, and old chats are not
normal boot material. Open a bounded historical source only when the current
canonical owner/source is insufficient for a specific recovery/evidence question.

## Stop Rule

If the current boot context is insufficient, open **one** relevant owner/source
next. Do not automatically broaden the scan.
