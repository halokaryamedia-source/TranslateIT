Template Rules / Sync Gate

Do not redraw

Every preview must come from DesignPreview source, not manual image composition.

Do not fork sidebars

Main sidebar and settings sidebar each have a single structure and class system.

State modifiers only

Recording, result, loading, and empty states change content/status without moving the shell.

No Tauri sync yet

Sync to the real app only after explicit user approval.
