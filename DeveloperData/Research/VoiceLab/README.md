# VoiceLab Research

## Purpose

This folder contains research notes for custom voice planning. It is not part of the active runtime route.

## Documents

- `VoiceLabResearchBrief.md` - product and technical research brief.
- `VoiceLabResearchNotes.md` - working notes and findings.

## Rules

- Keep research separate from runtime engine code.
- Do not introduce parallel runtime routes from this folder.
