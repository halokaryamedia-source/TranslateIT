# Launcher

## Purpose

`Launcher` is reserved for release launcher assets only.

## Current direction

TranslateIT uses the standard packaged executable generated by Tauri:

```text
EngineData/LauncherApp/RustApp/src-tauri/target/release/translateit_rustapp.exe
```

Final release packaging may expose this as:

```text
TranslateIT.exe
```

## Rules

- Do not store UI preview HTML here.
- Do not add script launchers here.
- Do not place runtime engine source here.
- Do not place Python worker code here.
- Keep the real app route inside `EngineData/LauncherApp/RustApp`.
